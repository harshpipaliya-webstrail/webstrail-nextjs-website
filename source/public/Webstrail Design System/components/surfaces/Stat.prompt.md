A single proof-point figure for stat rows. Earn every number.

```jsx
<Stat value="2" unit="yrs" label="Running Tooth Teller's platform" />
<Stat value="4" label="Dental products shipped" accent />
<Stat value="100" unit="%" label="Clients who stayed on retainer" onDark />
```

`accent` paints the value in solid orange; `onDark` lightens type for dark / signature-color bands.
