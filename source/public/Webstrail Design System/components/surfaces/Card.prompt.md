The base surface for content — case studies, feature blurbs, anything in a grid.

```jsx
<Card interactive accent>
  <Eyebrow>Case study</Eyebrow>
  <h3>Tooth Teller</h3>
  <p>Built and ran the core platform for two years.</p>
</Card>
```

`surface`: `white | soft | sand`. `padding`: `md | lg`. `interactive` adds a hover lift; `accent` adds the orange top bar. Render as `article`/`a` via `as`.
