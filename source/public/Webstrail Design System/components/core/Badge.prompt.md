A small pill for status and metadata — engagement state, vertical tags, stack flags.

```jsx
<Badge tone="success" dot>Ongoing</Badge>
<Badge tone="coral">Build + run</Badge>
<Badge tone="azure" outline>Open Dental</Badge>
```

Tones: `neutral | coral | azure | amber | success | danger`. `dot` adds a status dot; `outline` swaps the fill for a hairline ring.
